# Python for Finance: Analyze a Stock Portfolio With pandas

Companion materials for the Real Python tutorial.

- `fetch_prices.py`: Downloads adjusted daily closing prices with yfinance and saves them to `prices.csv`
- `prices.csv`: Snapshot of the prices used in the tutorial (2021-01-04 to 2025-12-31)
- `portfolio.py`: The finished portfolio analyzer

Run `python portfolio.py` to print the summary table and save `growth.png`.
