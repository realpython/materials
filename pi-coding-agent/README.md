# Should You Use the Pi Coding Agent? A Hands-on First Look

This folder contains code associated with the Real Python tutorial [Should You Use the Pi Coding Agent? A Hands-on First Look](https://realpython.com/pi-coding-agent/).

The `wordstats/` folder is a small Python project with a failing test, an `AGENTS.md` file, and a `.pi/` folder with a skill, a prompt template, and an extension. It also holds `ask_pi.py` and `rpc_demo.py`, which drive pi from Python. See `wordstats/README.md` for details.
