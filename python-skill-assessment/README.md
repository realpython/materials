# Python Skill Assessment: How to Evaluate Your Knowledge

This folder contains the materials for the Real Python tutorial [Python Skill Assessment: How to Evaluate Your Knowledge](https://realpython.com/python-skill-assessment/).

- `python-skill-assessment-worksheet.md`: The blank worksheet to fill in
- `python-skill-assessment-worksheet-example.md`: A filled-in example worksheet
- `probes/`: One short code probe for each level of the Python Skill Test

To check a rating, predict a probe's output, and then run it:

```console
$ cd probes/
$ python novice.py
```

The probes run on Python 3.15 and need no third-party packages, so there's no `requirements.txt`.
