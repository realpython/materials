# How to Refactor Python Code With an AI Agent

This folder provides the sample project for the Real Python tutorial [How to Refactor Python Code With an AI Agent](https://realpython.com/ai-refactor-python/).

Unzip the `ai-refactor-python.zip` archive to get the starter code: the RP To-Do app from [Build a Command-Line To-Do App With Python and Typer](https://realpython.com/python-typer-cli/) with a partial test suite, ready for you to refactor with an AI agent.

Unzip the `ai-refactor-python-final.zip` archive to get the finished project: the refactoring plan in `REFACTOR.md`, the characterization tests for the CLI, and the code after applying every refactoring in the plan.
