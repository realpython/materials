# How to Refactor Python Code With an AI Agent

This folder provides the sample project for the Real Python tutorial [How to Refactor Python Code With an AI Agent](https://realpython.com/ai-refactor-python/).

Unzip the `ai-refactor-python-starter.zip` archive to get the starter code: the RP To-Do app from [Build a Command-Line To-Do App With Python and Typer](https://realpython.com/python-typer-cli/) with a test suite that pins its current behavior, ready for you to refactor with an AI agent.

Unzip the `ai-refactor-python-final.zip` archive to get the finished project: the refactoring plan in `REFACTOR.md`, the Ruff, mypy, and coverage settings in `pyproject.toml`, and the code after applying every refactoring in the plan.
