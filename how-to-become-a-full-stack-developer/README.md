# Full Stack Roadmap Materials

Supporting files for [How to Become a Full Stack Developer: What Jobs Ask For](https://realpython.com/how-to-become-a-full-stack-developer/).

- `roadmap-checklist.md`: the printable checklist, one box per skill.
- `slice/`: a minimal full stack slice. A Node.js server sends JSON, and a
  web page fetches it and shows it. It needs Node.js 26 and no packages.

Run the slice:

```console
$ cd slice
$ node server.mjs
Listening on http://localhost:3000
```

Then open http://localhost:3000 in a browser.
