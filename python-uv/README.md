# Managing Python Projects With `uv`: An All-in-One Solution

This folder provides the code examples for the Real Python tutorial [Managing Python Projects With `uv`: An All-in-One Solution](https://realpython.com/python-uv/).

The sample app uses the [Cat API](https://thecatapi.com/), which requires an API key. Get one from the Cat API website and store it in an environment variable called `CAT_API_KEY` before running the app:

```sh
$ export CAT_API_KEY=<your-api-key>
$ uv run main.py Persian
```
