# Sales dataset

`sales_data.csv` is an unchanged copy of the fictional sales orders dataset distributed with Real Python's [How to Create Pivot Tables With pandas](https://realpython.com/how-to-pandas-pivot-table/).

- Original dataset: [Sales Data Presentation - Dashboards](https://www.kaggle.com/datasets/satyamanidharv/sales-data-presentation-dashboards), published by Kaggle user `satyamanidharv`.
- Download source: https://raw.githubusercontent.com/realpython/materials/master/pandas-pivot-table/sales_data.csv
- Retrieved: September 11, 2026
- License: Apache License 2.0, as listed by the original dataset publisher. The license text is included in `LICENSE-2.0.txt`.
- Size: 5,130 rows and 16 columns.

`sales_clean.csv` is generated by `src/prepare_sales.py`. It preserves all rows, renames `produce_name` to `product_name`, parses day-first dates and writes them in ISO form, and normalizes product-category capitalization. The original CSV remains unchanged. These changes are specific to the tutorial's prepared copy.
